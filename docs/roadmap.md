# Roadmap

0. Engineering foundation: FastAPI, then PostgreSQL and Docker.
1. LLM API and prompts.
2. Business knowledge RAG.
3. Safe SQL and tool calling.
4. Analysis tools and controlled agent.
5. LangGraph workflows.
6. Evaluation.
7. Deployment.
8. Enterprise permissions, security and human review.

Phase 0 complete: FastAPI and PostgreSQL run together in Docker Compose; both health endpoints have been verified. Phase 1 now implements the minimal DeepSeek chat path with usage reporting.

Future product direction: multiple providers/models, comparisons, platform-managed keys, BYOK, usage/cost tracking, user quotas and billing. These remain unimplemented.
